# vbz

The lossy AI image compression utility for Node.js.

Images are compressed into `.vbz` files (gzip-compressed visual descriptions generated by a Vision model like `gpt-4o`). Expansion feeds the description to an image generation model (`dall-e-3`) to hallucinate the image back into existence.

## Installation / Quick Start

Run directly with `npx`:

```bash
export VBZ_API_KEY="sk-..."
npx vbz compress -i photo.jpg
npx vbz expand -i photo.vbz
```

Or install globally:

```bash
npm install -g vbz
```

Or use as a library:

```js
import { compressImage, decompressImage, OpenAIClient } from 'vbz';

const client = OpenAIClient.fromEnv();
await compressImage('photo.jpg', 'photo.vbz', client);
await decompressImage('photo.vbz', 'reconstructed.png', client);
```

## CLI Usage

### Compress
```bash
npx vbz compress -i photo.jpg [-o photo.vbz]
```
*(If `-o` is omitted, `photo.jpg` defaults to `photo.vbz`)*

### Expand (Decompress to Image)
```bash
npx vbz expand -i photo.vbz [-o photo.png]
# or:
npx vbz decompress -i photo.vbz
```
*(If `-o` is omitted, `photo.vbz` defaults to `photo.png`)*

### Inspect Vibes
```bash
# Print stored description
npx vbz expand -i photo.vbz -t

# Query stored description with prompt
npx vbz expand -i photo.vbz -t -p "What colors are dominant?"
```

### Offline / Stub Mode
Test without an API key or network access using `-s` / `--stub`:
```bash
npx vbz compress -s -i photo.jpg
npx vbz expand -s -i photo.vbz
```

## Configuration

| Environment Variable | Description | Default |
| --- | --- | --- |
| `VBZ_API_KEY` | API Key (falls back to `OPENAI_API_KEY`) | — |
| `VBZ_BASE_LLM_URL` | Base URL for LLM/vision (falls back to `OPENAI_BASE_URL`) | `https://api.openai.com/v1` |
| `VBZ_BASE_IMAGE_URL` | Base URL for image gen | Falls back to `VBZ_BASE_LLM_URL` |
| `VBZ_LLM_MODEL` | Vision model name | `gpt-4o` |
| `VBZ_IMAGE_MODEL` | Image generation model name | `dall-e-3` |
